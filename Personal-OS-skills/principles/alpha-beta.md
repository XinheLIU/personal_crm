# Alpha vs Beta

## Definitions
- **Beta**：搭时代和行业「市场平均」的顺风车。仅会用 AI 属于通用能力，是 Beta。
- **Alpha**：扣除市场共识和通用收益之后，靠更高一层认知、判断和行动硬挣来的「超额收益」，是形成经济租的来源。

## Relationship: Alpha → Economic Rent
- **Alpha 是动能**：你主动出击、纠正错配的动作，是进攻
- **经济租是势能**：把 Alpha 的战果沉淀为品牌、专利、平台、默认入口、网络效应等防御堡垒
- 没有 Alpha，就很难积累真正厚实的经济租

## Three Accounts (三本账)
- **现金账（今天）**：现金流、利润、KPI
- **能力账（明天）**：今天的利润换回了什么别人学不走的能力
- **位置账（后天）**：能力沉淀成品牌、标准、默认入口、网络效应 → 即经济租

## Explore vs Exploit 张力
- 利用 (Exploit)：在熟悉打法上持续优化，是大部分公司和个人的默认模式
- 探索 (Explore)：挪出资源试新方向，会与当前业务优势形成冲突
- 路径依赖使「核心能力」变成「核心刚性」→ 给了后来者用新 Alpha 颠覆旧经济租的机会

## Classic Cases
| 失败案例 | 教训 |
|---------|------|
| Kodak | 沉迷传统胶卷降本，被数码时代淘汰 |
| Nokia | 自信于硬件效率，被 iPhone 改变竞争维度 |
| Kmart/Sears | 用财务优化对抗竞争，最终衰败 |

| 成功案例 | 策略 |
|---------|------|
| ASML | 不是继续挤 DUV，而是重注 EUV，持续再造 Alpha |
| 英伟达 | 打造 CUDA 平台，把学术界锁在 GPU 生态 |
| Airbnb | 看到「私人住宅闲置和信任缺失」错配，通过互评体系搭建平台 |
