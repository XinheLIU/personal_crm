# 经济租 (Economic Rent)

## Definition
经济租 = 收入中超出「维持资源继续提供所需最低报酬」的那部分收益。本质是通过「拥有关键卡位」来收钱，而不是通过「劳动本身」。

例：本来给 5000 元你就会干的工作，因为某种原因实际能拿到 20000 元，多出来的 15000 元就是经济租。

## Core Insight
赚钱要同时关注「创造价值」和「捕获价值」。核心问题是：你是否占住了别人绕不过去的位置？

心智模型：**收益 = 创造的价值 × 捕获系数**

- 创造的价值：决定你能不能进局、有没有资格上桌
- 捕获系数：决定蛋糕最后有多少留在你这儿

## Historical Evolution
| Thinker | Contribution |
|---------|-------------|
| 亚当·斯密 | 土地所有权会吸走高于正常工资和利润的剩余 |
| 李嘉图 | 地租理论：同样劳作下，肥地比薄地收益高 |
| 马歇尔 | 准租 (quasi-rent)：把租的概念从土地推广到机器、建筑、技能 |
| 塔洛克 | 寻租 (Rent-seeking)：真正的社会危害在于所有人都开始抢租 |
| 克鲁格 | 制度制造租：牌照、配额、竞争限制在制造租 |
| 马祖卡托 | 好租 vs 坏租（详见 [[good-rent-bad-rent]]） |
