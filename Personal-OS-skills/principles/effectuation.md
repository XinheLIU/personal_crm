# 效果推理 (Effectuation)

创始人：[[Saras Sarasvathy]]

## Definition
当目标不清、市场未成型、不确定性高时，不以目标出发，而以「我手里已有的资源」为起点，通过行动创造目标和新机会。

**核心一句话：「不知道该干什么的时候，先用你手里已经有的东西，干出一个会改变下一步的小结果。」**

## 效果推理 vs 因果推理

| 维度 | 因果推理 (Causation) | 效果推理 (Effectuation) |
|------|---------------------|------------------------|
| 前提 | 目标清晰、市场存在 | 目标不清、不确定性高 |
| 逻辑 | 先定目标 → 选手段 | 盘点资源 → 创造目标 |
| 类比 | 照菜谱做菜 | 冰箱里有啥就做啥 |
| 典型 | 造桥、量产手机、大公司成熟业务 | 创业、新业务探索 |

## 五大原则

### 1. 手中之鸟 (Bird-in-Hand)
先问「我已经有啥」而不是「我要达成什么」：
- 我是谁？（性格、偏好、价值观）
- 我会什么？（显性技能 + 默会知识）
- 我认识谁？（谁肯真投一手）

### 2. 可承受损失 (Affordable Loss)
- 传统：预测回报 → 再决定是否做
- 效果推理：假设不确定 → 先设定「能承受的最大损失」，在这个范围大胆试
- 本质：塑造「有限下行，开放上行」的反脆弱结构

### 3. 疯狂拼布 (Crazy Quilt)
- 优先找伙伴，不是先分析对手
- 带着粗糙想法找人谈：「如果你愿意提供XX，未来收入怎么分？」
- 承诺的多寡是强信号，帮你判断方向

### 4. 柠檬水原则 (Lemonade)
- 把意外当成新入场券
- 用户不爱整个产品却迷上小功能 → 新方向可能就是这功能
- 每次偏差反馈都可能是「真正方向」的线索

### 5. 驾驶舱里的飞行员 (Pilot-in-the-Plane)
- 放弃控制环境的幻觉，控制行动路径
- 你无法控制天气，但可以控制航向、燃油、速度、迫降方案

## 创业版 OODA 环
- **Observe** → 手中之鸟盘点资源
- **Orient** → 柠檬水原则解释意外，重构认知
- **Decide** → 可承受损失决定试错规模
- **Act** → 疯狂拼布发动外部资源

## Classic Case: U-Haul
1945 年退伍军人萨姆·肖恩从洛杉矶搬到波特兰，发现没有单程异地还车的拖车服务：
- 手中之鸟：5000 美元积蓄、改装拖车技术、亲友网络
- 可承受损失：几个周末 + 小钱
- 疯狂拼布：不自建门店，与各地加油站合作
- 柠檬水：从「租不到拖车」中挖出机会
- 结果：1945 年夏启动，1949 年已覆盖美国大部分地区
