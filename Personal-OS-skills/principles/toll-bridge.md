# 收费桥 (Toll Bridge)

## Definition
巴菲特提出的类比：两城之间只有一座桥，建好之后维护成本有限，之后就是长期「收过桥费」。好生意的共同点：生意结构里一定藏着一座收费桥。

## Core Logic
- 创造 vs 拥有：你可以非常勤奋、技术很好，但如果没有卡位，很容易被压价到只剩「辛苦费」
- 一旦你在价值链里握有不可替代的节点（入口、渠道、标准、平台、关键配套），就算「什么都不干」，也能反复收租
