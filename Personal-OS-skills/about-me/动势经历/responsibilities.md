## 业务视角

**职责**：负责 AI 与数据科学团队，面向医药、零售、消费电子等行业客户，设计并落地 AI Agent、数据智能产品与业务决策系统，推动企业从 AI 试点走向 AI 原生经营。带领 AI 工程师、数据科学家、产品 / 行业专家等跨职能团队，完成从业务诊断、方案设计、数据建模、智能体架构到生产落地的端到端交付。

**企业级 Agentic System 设计**
围绕销售、营销、渠道、库存、投放与管理决策等场景，设计「理解业务目标 → 分析数据证据 → 生成策略建议 → 编排执行动作 → 复盘学习优化」的智能体工作流，将大模型从单点问答升级为可嵌入业务流程的经营系统，降低人工分析与管理监督成本。

**AI 驱动的经营决策闭环**
结合行业知识、企业数据、外部市场信号与业务规则，构建面向销售 / 营销的策略大脑与执行闭环，支持门店运营、O2O 投放、终端动销、会员营销、销售管理等场景下的目标拆解、机会识别、资源配置与行动建议。

**数据科学与业务增长**
将因果推断、实验设计、增量 ROI 评估、用户 / 门店 / 商品分层、策略树拆解等应用于经营问题，帮助客户从「看报表」转向「找机会、做决策、推执行、看增量」，提升 AI 项目的可验证业务价值。

**跨行业 AI 解决方案落地**
主导或参与多个 ToB AI 项目，包括医药销售智能体、O2O 经营分析、品牌知识库与 AI 问药、零售门店经营诊断、消费电子人群洞察与 Offer 策略等，沉淀可复用的 AI Agent 产品框架、数据指标体系与行业解决方案。

**AI 原生管理模式**
推动 AI 从「工具层」升级为「管理层」与经营操作系统，探索用智能体承接部分业务分析、任务分发、过程追踪、异常预警与复盘归因，提升组织在复杂环境下的响应速度、执行一致性与管理杠杆。

## 技术视角（Agent 技术负责人 / Agentic AI Lead）

**定位**：不是只管人，而是自己能做架构、策略、评测、数据闭环、原型与技术攻关，下面再带数据策略、算法与工程团队。核心目标是把 Agent 从「能演示」推进到「可评估、可迭代、可交付、可规模化」。

### 1. Agent 技术架构与产品化落地

- 负责 Agent 整体技术架构，覆盖任务规划（Planning）、工具调用（Tool Use）、多轮交互、记忆机制、上下文工程、编排工程、执行反馈与自我优化等核心模块
- 主导 Agent 在代码生成、数据分析、运营决策、自动化执行、企业知识问答等场景的落地，形成可用、可靠、可评估的能力
- 与产品团队共建从想法孵化 → 原型验证 → 工程落地的闭环，对模型选型、Agent Scaffold 设计、工具链集成、系统架构演进与长期可扩展性负责

### 2. Agent 策略研发与能力提升

- 针对推理、规划、生成、指令遵循、工具调用、代码执行、多步任务完成等核心问题提出方案并设计实验验证
- 通过上下文工程、提示词工程、工作流编排、工具调用策略、任务拆解策略、反思（Reflection）机制、轨迹分析等手段持续优化任务完成率、稳定性与体验
- 深度分析 Claude Code、Cursor、OpenClaw、OpenAI Agents SDK、LangChain 等主流 Agent 产品 / 框架，提炼能力边界、失败模式与可借鉴的工程范式
- 跟踪 Agent / LLM / RL / 代码模型 / 多模态等前沿进展，快速复现并评估，推动有价值的方法在内部场景落地

### 3. 数据、训练与评测闭环

- 构建 Agent 评测体系：任务完成度、规划质量、工具调用准确性、代码规范、工程质量、可用性、多轮交互质量、稳定性、安全边界等多维度
- 设计并构造高质量评测数据集，精准区分不同模型与不同 Agent 架构的能力边界
- 与数据策略 / 标注 / 算法团队协作，定义标注方案、质量标准与评审机制，沉淀高质量训练 + 评测数据
- 通过数据 / 轨迹分析定位短板，针对性构建补齐数据、边界用例与失败案例集，形成「数据—训练—评测—策略优化」的持续迭代闭环

### 4. 强化学习与模型能力优化

- 参与 RL 在大模型对齐与 Agent 能力提升中的应用研究：RLHF / RLAIF / DPO / PPO / Actor-Critic / 过程奖励 / 偏好学习 / 轨迹级奖励等
- 与算法团队协作设计 RL 训练实验、奖励建模与能力可控性检测，从业务与数据侧支撑训练策略优化
- 关注推理、指令遵循、工具使用、代码生成、多步任务执行等能力的提升路径，并推动研究成果工程化落地

### 5. Agent 工程平台与基础设施

- 打通业界领先的 Agent 开发工具、外部 Scaffold 与内部训练 / 评测体系，构建高效的研发基础设施
- 维护 Agent 集成框架，支持便捷接入 RL 训练框架、评测平台、外部工具链与多种 Agent Runtime
- 搭建评测平台：任务执行、轨迹查看、调试分析、失败归因、可视化评估与实验对比
- 负责容器服务、运行环境、依赖管理、框架版本同步、执行稳定性与可观测性；解决并发执行、任务隔离、工具权限、环境复现、日志追踪与成本优化等工程问题

### 6. 团队协同与技术管理

- 作为 Agent 方向技术负责人，带领数据策略、算法、工程开发等角色完成研究 → 实验 → 评测 → 产品化的全过程
- 把复杂业务问题拆解为可验证的技术问题，再拆解为数据 / 算法 / 工程 / 产品可执行的任务
- 负责关键方案评审、技术路线判断、项目节奏与跨团队协调；在关键技术难点上亲自下场做原型、跑实验、看轨迹、分析失败
- 沉淀团队方法论：评测标准、数据规范、实验流程、工程规范与复盘机制

## 关键技术栈与能力锚点

- **大模型与 Agent**：LLM 推理 / 上下文窗口 / Function Calling / RAG；Planning / Tool Use / Memory / Reflection / Multi-agent / Workflow Orchestration
- **训练与对齐**：SFT / LoRA / QLoRA；RLHF / RLAIF / DPO / PPO 等偏好学习与过程奖励
- **部署与推理**：GPTQ / AWQ / KV Cache / 推理加速等量化与部署优化（了解）
- **工程**：Python（主力）、PyTorch、FastAPI / 后端 API、Docker / Linux / Git / CI/CD；评测平台前端可用 React / Vue 搭建轨迹与调试可视化
- **框架与工具**：Cursor、Claude Code、OpenAI Agents SDK、LangChain / LangGraph、LlamaIndex、Playwright MCP、Browser Agent 等

## 一句话定位

> 既懂模型能力提升，也懂数据与评测闭环；既能做 Agent 架构设计，也能亲自写原型、跑实验、看轨迹、分析失败案例；既带团队，也在关键技术问题上自己下场。
