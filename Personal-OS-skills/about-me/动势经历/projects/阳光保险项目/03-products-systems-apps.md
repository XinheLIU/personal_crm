# 03 — 产品 / 系统 / app 矩阵

> Last updated: 2026/05/05

## TL;DR

阳光的产品矩阵分**对客**和**业务员**两类。**对客 app**：财险官微 / 阳光车生活助手 / 精准营销 / 农险向日葵 — 关键收敛动作是**机构 70 个 app 关掉了**（典型的"项目→平台"前奏）。**业务员工具**：全能保 / 同心保（内核）/ 综拓 / 几包融合。**底层系统整合**通过梦客（电销新渠道）打通前端和直销。**6 个统一**和**两个 app（代理人用）**是整合方向。**三张生命表**（车险 / 非车 / 信保 — 详见 [01](01-insurance-and-org.md)）通过业务员工具落地。**伙伴行动**（产险）：仓储 / 预警 / 物联网设备。

---

## 底层系统整合

- **底层系统整合 — 急事 — 梦客**
- **电销 → 新渠道；梦客 — 自营 — 直销**
- **整合**：
  - **前端**和**直销**打通
  - **中间对接**统一的
