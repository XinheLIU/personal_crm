# 01 — 保险行业 & 阳光组织 & 战略节奏

> Last updated: 2026/05/05

## TL;DR

保险行业的本质结构是**「共享中后台 + 业务条线」**两层切分（共享 = 战略企划 / 投资 / 精算 / 风控 / 人力 / 财务 / 客户管理 / 信息技术 / 监察稽核等；业务条线 = 个险 / 银保 / 经代 / 车险 / 非车 / 资管等 18+ 个）。阳光在这个结构上叠加了**「九大灯塔」**（客户 / 人力 / 企划 / 精算 / 财务 / 投资 / 集合 / 风控 / 行政办公）+ 子公司数据中台。**集团内自上而下逻辑集中、主体内物理集中**是阳光的总体集中模式。**价值排序：客户 > 精算 > 人力财务 > 企划投资风控集合行政办公**；**成熟度排序：客户最高 > 财务精算企划**。「**大灯塔 vs 替代率**」是当前战略 framework 之争（企划老总主推大灯塔、强调一步步躺过来 / 大灯塔距愿景近 / 按替代率逻辑 + 抓 25→26 年目标）。**阳光首先引入寿险生命表做寿险定价模型 + 产险定损模型**（车险 / 非车 / 信保 三张生命表）。科技人员 500-600（其中 AI 几十号、400→300 人在迭代；中台最大团队 60 号人）。

## 保险行业生意模式 — "三多一高"

> 保险这个行业的生意模式，可拓展到金融的"三多一高"：[https://metaso.cn/s/Bgb2Q5K](https://metaso.cn/s/Bgb2Q5K)

行业的核心组织结构：**共享中后台 + 业务条线**。

### 共享中后台（中台共享服务）
- 战略企划
- 投资管理
- 精算管理
- 风险合规
- 人力资源
- 财务管理
- 品牌宣传
- 招采物控
- 党群行政
- 客户管理
- 信息技术
- 监察稽核

### 非共享 — 前台业务条线（按业务 / 渠道划分）
| 板块 | 条线 |
|---|---|
| **寿险渠道** | 个险 / 银保 / 职团 |
| **保险销售渠道** | 电销 / 网销 / 经代（经纪 / 代理） |
| **产险核心** | 车险 / 非车（如责任险、农险）/ 财产险 |
| **意健险** | 意外险 + 健康险 |
| **信保** | 信用保证保险 |
| **理赔作业** | 产险 / 寿险理赔业务 |
| **资管 5 类** | 投资 / 研究 / 销售及渠道管理 / 风险控制及投后管理 / 项目管理 |

## 阳光组织结构

### 三层视角
- **管理**：客户 = 客价部
- **建设**：科技为主项目组；产寿子公司
- **执行 / 使用方**：
  - **寿险** — 纵横研究与客户运营部（增值服务、家庭洞察、线上运营）
  - **产险** — 消费者运营保（客价部门）
  - **机构** — 负责管理政策、工具落地、推动
  - **总部** — 机器人交叉的 [?]

### 九大灯塔
- 客户
- 人力
- 企划
- 精算
- 财务
- 投资
- 集合
- 风控
- 行政办公
- + 子公司数据中台（独立一层）

### 集中模式
- **主体内**物理集中
- **业务条线**
- **集团内**自上而下逻辑集中

### 排序
- **价值**：客户 > 精算 > 人力财务 > 企划投资风控集合行政办公
- **成熟度（数据量）**：客户成熟度最高 > 财务精算企划

### 部门 / 共享职能
- 财务、人力、办公、风控等公司**统一管理**
- **底层都是王哲总**（科技底层 / 平台层负责人）

### 内容中心
- 阳光关键信息：**有个内容中心**

### 当前现状
- **裁员很厉害**
