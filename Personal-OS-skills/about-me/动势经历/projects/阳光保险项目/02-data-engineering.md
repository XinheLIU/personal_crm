# 02 — 数据工程 & 客户数据 & 智能中台

> Last updated: 2026/05/05

## TL;DR

阳光数据工程的核心 framework 是**三步：采集 → 价值分析 → 价值推送**。**采集**有三种数据源（自有 / 死信息激活 / 三方生态合作）；**价值分析**核心是定义谁用 / SLA / 质量评估标准；**价值推送**是营销路径识别 + 推送给业务员。**客户数据工程**关注的指标是购买力 / 购买意愿 / 概率 + 服务信息。**核心难题：归因难**。**智能中台**已经在做：数据层 TDS 在做 4.0；模型管理 3 个平台（分类 / 文本 / 图像 / 语音）；专业平台（理赔 / 养老 / Qwen2.5）。**中台泛化**是关键趋势。教授提了一个延伸方向：**社交数字化做社交数据资产**。

---

## 数据工程三步框架

### 1. 数据采集
三种数据源：

1. **自有数据**
2. **死信息激活** — 把已经存在但未被利用的信息激活起来
3. **三方生态合作数据** — 直接 & 间接两类

### 2. 价值分析
核心问题不是"分析什么"，而是"谁用 + 怎么衡量"：

1. **谁用** — 业务员
2. **质量评估标准** — SLA 是什么

### 3. 价值推送
1. **营销推动 — 路径识别**
2. **推送到业务员**
