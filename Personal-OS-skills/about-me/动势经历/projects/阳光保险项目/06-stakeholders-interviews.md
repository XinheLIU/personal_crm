# 06 — 关键人访谈记录 + 后续访谈清单 + 项目待办

> Last updated: 2026/05/05

## TL;DR

4 位关键访谈者，4 种视角的张力：**徐博士**（科技 / 智能体技术，"技术问题都可以解决，关键是梳理业务流"）;  **团长**（业务现实视角，最尖锐 — 数据稀疏 / 销售人员合同关系 / 飞单 / 阳光自下而上不 work / 个险终局但端分散没流量没数据 / 业务陪跑 to Agent + to C 阳光变成平台赋能 Agent 给联盟）;  **冰冰**（中间整合视角 — 销售+服务＆管理 / 内勤驱动产售会模式 / AIA 友邦专业代理人方向 / 但被尹铭说"产销会不靠谱"）;  **教授**（方法论视角 — 试验田 / AB 实验 / 持续迭代 / 王睿反馈"自下而上→自上而下" / 科技交付的应该是业务模式和业务场景 / 整体智能体运营能力）。**后续访谈清单**（去重后单一版本）覆盖机器人价值 / 拉通 / 6 个统一 / 知识库 / 智能中台等 5 大块。**项目 3 大待办**：上述问题确认 + 触点设计 + 智能体技术选型。

## 访谈 1：徐博士（科技 / 智能体技术视角）

### 嵌入路径
- **大部分插件嵌入**
- **销售培训系统：高频嵌入**
  - 可以做客户模拟 + 强化学习反馈
  - 知识库
- **理赔**
- **核保 / 定价**

### 平台 vs 培训之争
- **平台驱动 → 交互方式要人优化**
- 还是推**培训 → 销售智能体**

### 理赔智能体技术难点
- **AI 模型服务化 + 数据资产化（算力 & 数据）**
  - 内部 API 访问 — 类似 **MCP** 后台服务复杂度比较高
  - 内部资源 / 知识 / 服务 → 变成服务 → 赋能给业务员
  - **让业务员少承担风险**
- **阳光反馈（顾青山）**：
  - 之前是规则 / 逻辑 / 业务逻辑 — 坐在传统系统里面
  - 智能体需要重新 **orchestrate**
  - 以及要**控制 + 稳定性**

### 核心结论
- 觉得**技术问题都可以解决**
- 关键是**梳理现在业务流是否可以**

### 算力调度 / 知识库
- **R1 后面可以蒸馏**

## 访谈 2：团长（业务现实视角，最尖锐）

### 数据问题
- **客户画像没有**：
  - 阳光保险**购买比较稀疏 + 是被动购买 + 与业务员能力相关**
  - **只有结果数据**
- **销售人员是合同关系**：
  - 同时代理平安 / 友邦 → 控制力弱
  - 销售人员在平台练习不太可能 → **RLHF 有水下分佣协议**
  - 有**飞单问题**
  - **陪练现在的目的：从 0 到 1**

### 访问端
- **哪个端访问** [?] *（待澄清）*

### 机会
- **销售：需要一个销售人员的辅助**
- **不一定需要 AI 化**

### 诉求
- **业务对技术抱怨正常**
- 应该呼吁**加大对科技投入**：保费 / 单量
- 技术：
  - 用模型 / 模型选型
  - 算力怎么改进
  - **薪酬人才 — P78 250w 招人招不来**
- **让业务懂技术（王睿）**：
  - 觉得技术觉得科技侧做得不是他们要的
  - 午餐会明说了 → **要理顺生产关系 / 理顺和业务的关系 / 理顺**

### 终局看法
- **个险是终局** — 但现在端分散 / 没有流量 / 没有数据
- 没有用户直接使用 app — 是**营销员用** → app 体验不好 → 用户不直接使用
- 业务现在没有规划 → 规划梳理不出来
- **以客户为中心** 应该是 **业务陪跑 → to Agent + to C，阳光变成平台赋能 Agent 给别的联盟**

### 觉得自下而上不 work
- **下一代场景看不清**（科技承担风险还是比较大）
  - 例：蚂蚁 → 教育 → 人寿保险 — 现在看不清
- **梦客**基于未来的互联网，负责了两三年做了个新渠道 — **做不起来**
- **试点也要业务提**：
  - 业务不会认 + 有利益（四级保险机构也能活得好）
  - **不要提新模式，可以说做实验**

### 机器人看法
- 销售服务管理还是要先回答**董事长问题**
- 觉得**场景改变浪费时间**

## 访谈 4：教授（方法论 + 创新视角）

### 试验田模式
- **小规模试点 + AB 实验 + 持续迭代**
- **王睿反馈**：
  - 之前考虑过**自下而上**打破现有管理体系的模式（**单推不动**）
  - 现在是**自上而下整体规划**的模式

### 科技交付的本质
- 应该是**业务模式 + 业务场景**
- 最后是**整体智能体运营能力**

### 创新方向
- 要**迭代产品交互方式 → 创造新场景**

### 数字化方向
- Eg **社交数字化 → 做社交数据资产**（与 [02 数据工程](02-data-engineering.md#社交数字化教授延伸方向) 同步）
