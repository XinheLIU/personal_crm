# 04 — 项目本身：特色店规划方案

> Last updated: 2026/05/05

## TL;DR

项目核心交付是一套面向 T2 的**「特色店」战略**，通过四维框架把"标品 + 强控盘 + 弱毛利"困境下的苹果经销商重新拉到差异化竞争上：**1) 市场规模探查 → 2) 用户需求细分 → 3) 渠道规划建议 → 4) 落地效果评估（AB 实验）**。流量端打阿里系 APP 矩阵（高德 / 钉钉 / 支付宝 / 夸克）+ 用户数据；产品端是非标门店设计 + 差异化供给（产品 + 权益）+ 场景化营销；心智端建立特色店品牌（如「Apple 游戏发烧专区」）跨平台统一透出，考核用户主动搜索量。项目专业度获认可，但终局思考不够、对客较多依赖孙老师；至 2025/11 因预算收紧由张岩接手。

## 特色店规划核心方向（四维框架）

### 1. 市场规模探查
- 重点关注**官旗及渠道店的用户规模 / 市场规模盘点**
- 关键数据点（来自项目调研）：
  - 淘店用户规模约 **2000 万**
  - 官旗用户占大头
  - 非 8VIP 用户约 **1.1 - 1.2 亿**
  - → 渗透率提升空间巨大

### 2. 用户需求细分
- 细分垂类用户：**学生 / 体育发烧 / 游戏发烧友 / 商务出行**等
- 结合**换机节奏 + 渗透情况**形成人群包
- 关键洞察：
  - **8VIP 人群占苹果手机用户 70%**
  - **游戏人群 iOS 设备占比 48%** → 需要针对性运营
- 挖掘用户拓展与渗透结果

### 3. 渠道规划建议
- 基于**细分人群 × 场景**（新品发布、开学、春节送礼）
- 提供**准实时**的渠道业务规划建议
- 例：出行店按场景设计产品布局，非标准产品排列

### 4. 落地效果评估
- 配合用户需求细分 + 渠道建议
- 设计 **AB 实验**：对比不同门店设计、营销素材的转化效果
- 评估策略对**天猫渠道增量价值**

## 多平台赋能（阿里体系）

利用阿里系 APP 流量与数据：

### 流量导流
通过多 APP 矩阵透出门店：
- **高德** — 位置场景 / 出行
- **钉钉** — 商务人群（飞书等场景下接收门店广告）
- **支付宝**
- **夸克**

→ 商务人群在不同 APP 接触苹果门店广告的多触点心智构建

### 数据共享
- **钉钉**：企业设备需求、人力结构
- **高德**：位置服务（如分析古镇游客设备类型 → 辅助选址）
- **支付宝 / 夸克**：用户行为数据 → 赋能门店运营

## 差异化供给与营销

避免与官旗在价格上硬碰硬（详见 [01 商业模式](01-business-model.md) 中"控价 / 标品"分析），用三件事做差异化：

### 1. 非标门店设计
- 围绕场景定制非标准化设计
- 例：
  - **出行店** — 以「飞机出行」为标签，产品与场景强关联
  - **游戏店** — 围绕游戏发烧人群

### 2. 差异化供给
- **产品**（如充电器）
- **+ 权益**（如**飞猪联动权益** — 出行场景下的跨业态权益）

### 3. 差异化营销
- 避免价格竞争
- 围绕**场景制作素材**（出行店营销聚焦出行需求）
- **精准定向人群投放**

## 用户心智建设

### 建立特色店品牌
- 例：「Apple 游戏发烧专区」「出行特色店」
- **跨平台统一透出**：
  - 淘天
  - 京东
  - 线下
  - 异业联名

### 考核指标
- **用户主动搜索量** —「用户主动搜索 'Apple 游戏发烧专区'」
- 这是心智建设的硬指标
