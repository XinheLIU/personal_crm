# 07 — 项目反思 & 咨询方法论 & 阿里组织观察

> Last updated: 2026/05/05

## TL;DR

苹果项目带出来的元层学习有四块：1) **如果重做项目怎么做**（先了解业务+组织 → out-of-box → Business driven AI first → 注重五项积累）；2) **PE Ratio 提估值的两大支柱**（战略想象空间大 + 实现路径可信）这是从动势 BS Group 的视角看的资本叙事框架；3) **Make-a-Deal 思维**（孙老师风格 — 从锚都没有到 datavendor → 认证 → 沙盒 → 阿里人进来干活，build/sell/get lucky 的体感、用资源/利益/诉求解构一切、定义/被定义、taste 的重要性）；4) **阿里组织观察**（P7→P10 阶梯：P10 知道生意 / P9 推动 deal / P8 拿绩效 / P7 找生态位 — 字节 vs 阿里都是组织效率问题，关键还是创始人）。元结论：减少对合伙人依赖，独立做深度决策。

---

## 1. 如果重做这个咨询项目，怎么做？

### 1.1 先了解业务 + 了解组织
- **算财务指标**（不只是看，而是自己能算）
- **组织信息**：核心人员画像 + 核心 KPI
- **设计可能的战略落地路径** → 带着目标去访谈（不是开放性收集，而是带假设验证）

### 1.2 有 out-of-box 的 thinking
- **起码逻辑是自洽的**（孙老师风格）
- 最好能 **fast prototyping** 甚至跑通闭环（Andrew Ng 风格）
- 这是从"咨询输出 PPT"过渡到"咨询输出可验证 demo"的方法论升级

### 1.3 Business driven, AI first
- 当前的自我反思：**不够懂商业**
- → 需要补 business sense

### 1.4 注重积累（五项）

1. **商业理解** — 尤其是这一行里面的【核心竞争点、关键难题、考核指标】+【数据闭环 / AI 可以落地场景】
2. **行业理解** — 这一行为什么存在、里面的人怎么想
3. **AI 落地理解** — 正面 + 负面（**认知阻力 + 能力阻力 + 组织阻力** 的理解）
4. **动手与重构经验**
5. **思考未来** — 积累对于本质的理解
6. **人脉关系** — 真正学会利用人脉（像孙老师 — 但**这些都没有做到**）

> 自评：第六项是最大的差距点

## 2. PE Ratio 提升估值的两大支柱

> 来源：动势 BS Group 框架；右上角标注外部顾问可参与

### 核心定义
- **目标**：提升二级市场上市的市盈率（PE ratio）
- **本质**：创造更大的所有者权益（长期增长性、盈利性）

### 支柱一：战略想象空间大
*让资本市场听到快速增长的故事*

1. 占据**增长更快、风险更低的细分市场**（经济增速 + 资本市场增速）
2. **公司本身利润增速加快**：商业模式 / 利润结构改变、扩张并购
3. **潜在利好**：垄断牌照、AI 应用等

### 支柱二：实现路径可信
*资本市场相信融资后能执行相关战略*

1. **数据驱动的业务规划**
2. **团队 + 组织能力**
3. **过往试点有成功案例**，大概率能成功复制

### 这个框架对项目层的启示
- 苹果项目本身（特色店方案 → [04](04-project-framework.md)）就是一个微缩版本：
  - 战略想象空间大 = 8VIP 渗透率扩大、人群细分新增量
  - 实现路径可信 = AB 实验 + 阿里系数据赋能 + 跨平台心智 → 数据驱动 + 可复制
- → 咨询方案的"可被相信"是核心交付物

## 3. Make-a-Deal 思维（从孙老师学到）

### 3.1 项目本身就是一次 Deal-Making
- 起点：**数据都没有**
- 中间：画饼 → 拉天猫 → 给 AI 画更大的饼
- → 闭环走通了
- 体感：**做生意 = 梦想牵引 + 走一步看一步**

### 3.2 路径回放（锚的迁移）
- 锚都没有
- → datavendor
- → 认证
- → 弄沙盒合作（**类似贝恩模式 — 8 大人群是贝恩搞的**）
- → 竟然还就走通了
- → 甚至让阿里的人进来干活

### 3.3 Build / Sell / Get Lucky 的体会
对这个框架有了更多体会，跟孙老师学到了：

- **一种视角 — Make a Deal**：学会用**资源 / 利益 / 诉求**的视角去思考和解构一切
- **商业模式层面的思考** — 真的要找到那个**巧劲**的点
- **多看商业模式** — 打开思考的大门
- **重构 — Everything on the Table** — 定义、被定义，还是蛮有意思

### 3.4 对生态位有了不同体会
- 这是核心的元收获
- 苹果项目本身是一个生态位实验：动势找到自己在阿里 × 苹果 × T2 中间的位置

### 3.5 "定义 / 被定义"的真正意思 — 从做 PPT 体现

- **Taste 的重要性**：stand on 自己有什么去 sell
- AI 能学到品味吗？*（开放问题）*

## 4. 阿里组织观察（P7 → P10 阶梯）

阿里交流一下午，能感觉出 P7-P10 之间的差距：

### P10 — 知道生意
- 资源 / 生态位 / deal / 规模空间这一类的事情
- 从 P7 升到 P10 真的需要**碰上好业务** — 哪里都一样
- 替代方案：还不如外面创业 / 做生意 — 年纪轻轻就能到 P10
- 还是要 **Go-to-Market** — 这是应该交给孩子的

### P9 — Make-Deal Sense
- 有 make-deal 推动事情的 sense
- 是 P10 的雏形

### P8 — 老板预期 + 拿绩效 Sense
- 知道老板要什么
- 能稳定拿绩效

### P7 — 找生态位 Sense
- P7 里能升上去的人 — 懂找生态位
- 这是从执行层走向决策层的拐点

### 组织效率：阿里 vs 字节
- 其实人和字节差不多 → 还是**组织效率**的问题
- 也能看出马云回来这半年好了不少
- → 还是需要**创始人**
- 如果再回流去字节，感觉还是得去 **seed**（早期项目 / 0→1 阶段才有空间）

## 6. 元结论 — 个人成长锚点

### 6.1 项目层面的两个差距点
- **终局思考不够 / 长期业务价值前瞻不够**
- **对客较多依赖孙老师指导**

### 6.2 接下来要做的事
- **减少对合伙人依赖、独立完成深度决策**
- 把上面的"五项积累"逐项做实
- 特别是第六项（人脉关系 — 像孙老师那样真正用起来）

### 6.3 提升估值的本质 — 项目层 + 个人层都通用

> 创造更大的所有者权益

放到个人层：长期增长性 + 盈利性 = **能力增长曲线 + 当期可变现度**。两者都要打。
