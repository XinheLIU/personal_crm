# 03 — 经销商对标分析（华硕 / 华为）

> Last updated: 2026/05/05

## TL;DR

**华硕 = 经销商成功公式的样板**：人群抓得住 + 多平台授权 + 子品牌打法（ROG × KFC、华硕赛车、华硕娇兰）+ 库存 / 人员全复用 → 在和苹果完全相同的毛利结构（4.X% / 手续费 2.6 / 物流 0.5 / 税 1）下做到 1-3 个点 net profit，而苹果同行亏钱。**华为 ≈ 类政府逻辑**，官网直接 8500（4 个点），线上不好做。差异化生存路径不是价格，是「B2C 特色店 + 异业联名 + 锁定细分行业的核心资源」。MDF（市场发展基金）品牌报销 2 个点是经销商利润空间的关键来源。

## 华硕特色店 — 成功公式拆解

### 1. 人群抓得住
- 「人群抓住了」是第一性
- 懂的就懂 — 流量成本、转化效率，圈层精准

### 2. 多平台授权 + 拿了官方旗舰店
- 经销也压货
- 多平台授权（不是单点押注）

### 3. 子品牌打法（核心溢价空间）
- **ROG 数码领域** — 流量最高、话题最多
- **联名活动**：
  - ROG × KFC
  - 华硕赛车
  - 华硕娇兰
- 话题、联名、链接 — 2w 32 [?] *（具体指标含义不明，可能是某次联名带来的流量 / 转化数据）*

### 4. 毛利结构（与苹果完全相同 → 但能赚钱）
- 总毛利 4.X%
- 天猫手续费 2.6%
- 物流费 0.5%
- 税点 1%
- → 线上 net profit 1-3 个点
- 子品牌（如 ROG）能再撑高 3 个点空间 [?]

### 5. 资源全复用 + 高流动性
- **库存全复用**：库存流动性 → 库存降低 → 可以调配
- **人员复用**：客服 / 设计 / 共享
- **投流策略**：线下完全不投；线上看站点 [?]

### 6. 商场租金机制
- 有些商场是租金 + 流水提点（提点不太高 → 不加 [?]）

### 7. LBS / 新加坡场景拓展 [?]
- *原文："3 个点）；线下成本低一点 ... LBS 新加坡"*
- 含义：可能指华硕在新加坡的 LBS 试点 / 或者在新加坡用 LBS 思路做线下

### 8. 品牌报销机制（MDF）
- **品牌报销 2 个点** — MDF（Market Development Fund）
- 华硕这种 → 2 个点
- 是经销商利润空间的核心一部分

## 苹果经销商的差异化生存路径

苹果经销商在标品 + 强控盘 + 弱毛利的结构下亏钱（详见 [01 商业模式](01-business-model.md)），生存解：

### B2C 特色店
- 围绕场景 / 人群做非标设计
- 与差异化供给（产品 + 权益）+ 差异化营销（场景素材）共同形成壁垒
- 详见 [04 项目框架](04-project-framework.md)

### 异业联名（向华硕学）
- 华硕 × KFC、华硕娇兰、华硕赛车 → 苹果可以套用类似打法
- 教授后面也聊到了手表 *（暗示苹果可以围绕 Apple Watch 等可穿戴做联名 [?]）*

### 锁定细分行业核心资源
- **健康** 锁定一些核心资源 → 利润空间撑起来
- 这是行业特色路径（医疗 / 健康 / 教育 / 出行）

## 运营商渠道 / 教育 enterprise

- 苹果渠道还有运营商
- 教育 / enterprise 这条线压缩很惨（Stella 负责）

## MDF 报销机制（品牌返点）

- **品牌报销 2 个点**（华硕这种）
- 是 T2 利润空间的关键一环
- 项目工作线中 LBS 投放钱的一个潜在来源 → 详见 [05 工作线](05-workstreams-pop-lbs.md)

## 关键洞察 — 同样毛利结构，为什么华硕赚钱苹果亏钱？

抽象出来三层差异：

1. **品类话题度**：ROG 在数码圈是话题中心（联名、KOL、话题营销可放大）；苹果作为标品 + 强控盘，话题溢价空间被官旗收走
2. **子品牌灵活度**：华硕可以做 ROG / TUF / Republic / 一系列子品牌做差异化；苹果产品线高度收敛
3. **库存 / 人员灵活度**：华硕全复用、苹果操盘空间只 30%、品牌干预多

→ 苹果经销商生存策略不能照搬华硕，必须是**找到苹果体系内允许的差异化空间**（特色店、人群细分、异业联名、O2O 服务、私域沉淀）
