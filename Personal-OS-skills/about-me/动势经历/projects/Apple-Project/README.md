# Apple-Project — 动势 × 苹果中国 经销商咨询项目

> Last updated: 2026/05/05

## 一段话背景

2025/6 起承接的咨询项目：与天猫 / 阿里体系合作，围绕「特色店」战略为 T2 经销商重塑增长路径（用户需求细分 × 渠道规划 × 阿里系流量赋能 × 差异化供给）。专业度获客户认可，但对客较多依赖孙老师指导、终局思考不够；至 2025/11 因预算收紧，由张岩接手。本子文件夹是把项目期间的流水反思（[原始笔记](../Apple-Project-25.md)）按主题重新整理的成果。
