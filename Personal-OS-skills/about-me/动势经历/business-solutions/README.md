## 战略与市场笔记（26-3）

1. **生态位**：仍是咨询公司属性
2. **客户会买单的方向**
   - 标准化能力的生态伙伴（抖音、小红书、投流）
   - 华与华类品牌预算
   - 媒体 / 银发看电视等广告预算；不做 O2O（例：通过广告 / 空军打法提升人效）
3. **客户倾向自建**：部分事情客户希望自己掌控（如销售端相关）
4. **偏 ToC、通用化可卖**
   - 特聘顾问、会员管理、门店打造、朋友圈运营等
   - 孙老师的 CRM 方向仍有很高价值
5. **孙老师企业侧**
   - 商务策略 / 管理 / 内部「科研」投产比
   - 缺少特别核心、不可替代的标准化动作 / 偏差管理 — 内部「Core」尚未打牢
